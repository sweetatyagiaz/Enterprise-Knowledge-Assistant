# Screenshots and demo checklist

Use real screenshots from the running application. Do not publish fabricated UI images as if they were captured from the product.

## Recommended assets

Save approved assets in `docs/images/` and reference them from `README.md`.

1. **API documentation:** Swagger UI showing the actual routes.
2. **Document ingestion:** A successful upload/index response using a public or synthetic document.
3. **Question answering:** A representative question, answer, and returned source information.
4. **Evaluation report:** A sanitized view of the retrieval evaluation metrics.
5. **Short GIF or video:** Upload a sample document, ask a question, and inspect the sources.

## Before publishing

- [ ] Confirm all screenshots came from the real running application.
- [ ] Remove API keys, tokens, email addresses, personal data, private file names, and confidential content.
- [ ] Use a public or synthetic example document.
- [ ] Verify displayed values match the current version.
- [ ] Add alt text to README images.
- [ ] Keep the demo short and include any setup prerequisites.
